# Artwork template PDFs

Drop the print-ready template PDFs here with these exact names:

- `canopy-10x10-template.pdf`
- `canopy-10x15-template.pdf`
- `canopy-10x20-template.pdf`

They appear as download links on each product's **Template** tab. Until a file
exists the link 404s (the tab still shows), so upload before announcing.
Add more per-size or per-wall files by editing `templatesFor()` in
`src/components/ProductTabs.jsx`.
