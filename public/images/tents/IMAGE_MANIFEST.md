# Tent & table-cover image manifest

The site auto-selects these by filename. To replace one, drop a new file with the
**same name** (any format the browser reads; keep `.webp` and re-optimize if you can).

## Canopy tents — `public/images/tents/`

Per size (`10x10`, `10x15`, `10x20`), the product preview swaps by wall setup:

| File | Configuration |
|------|---------------|
| `<size>-full3.webp` | Full setup — 3 full walls |
| `<size>-back.webp`  | 1 full wall (back) |
| `<size>-half2.webp` | 2 half walls (sides) |
| `<size>-half1.webp` | 1 half wall (front) |
| `<size>-none.webp`  | Canopy only (no walls) |
| `<size>-1wall.webp` `-2wall.webp` `-3wall.webp` | Count-based aliases used by cards / home / size pages |

## Table covers — `public/images/table-covers/`

| File | Used for |
|------|----------|
| `pleated.webp` | Main image for the 4/6/8 ft **Pleated** options |
| `stretch.webp` | Main image for the 6/8 ft **Stretch** options |
| `plain.webp` `pleated-alt.webp` `fitted.webp` `runner.webp` `round.webp` | Gallery / not current SKUs (runner + round aren't sold yet) |

Artwork on all of these should be Apex or neutral, not the demo brands
(Northridge / Elevate / Pioneer / EcoHarbor / etc.).
